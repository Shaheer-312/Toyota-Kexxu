Phase 1: Core System & Hardware Drivers

Before Python can even look at the cameras, the Linux kernel needs the right tools to talk to the USB bus.

1. Update the system registry:
Bash

sudo apt update && sudo apt upgrade -y

2. Install the Video4Linux toolkit & FFmpeg:
You need v4l-utils for your exposure locks and ffmpeg for quick pipeline verifications.
Bash

sudo apt install v4l-utils ffmpeg -y

Phase 2: The Python Sandbox (Avoiding OS Conflicts)

Remember that externally-managed-environment error you hit last time? Ubuntu protects its core Python files. We are going to build a dedicated virtual environment for your project so you have total control.

1. Install the Virtual Environment manager:
Bash

sudo apt install python3-full python3-venv -y

2. Create your Project Folder & Environment:
Bash

# Make the project directory and move into it
mkdir -p ~/Toyota-Kexxu && cd ~/Toyota-Kexxu

# Create the isolated environment named '.venv'
python3 -m venv .venv

# Activate it (You must do this every time you open a new terminal to work on the project!)
source .venv/bin/activate

(You should now see (.venv) at the start of your terminal prompt).

3. Install your low-level dependencies:
Bash

pip install linuxpy

Phase 3: The Hardware Symlinks (udev Rules)

We need to lock your cameras to /dev/eye and /dev/front permanently, filtering out the "ghost" metadata nodes so the system never gets confused.

1. Open the rules file:
Bash

sudo nano /etc/udev/rules.d/99-kexxu-cameras.rules

2. Paste your exact, index-filtered rules:
Bash

# Eye Camera (Microdia/Sonix) - Video Capture Node Only
SUBSYSTEM=="video4linux", ATTRS{idVendor}=="0c45", ATTRS{idProduct}=="6366", ATTRS{serial}=="SN0001", ATTR{index}=="0", SYMLINK+="eye"

# Front Camera (Realtek) - Video Capture Node Only
SUBSYSTEM=="video4linux", ATTRS{idVendor}=="0bda", ATTRS{idProduct}=="5842", ATTRS{serial}=="200901010001", ATTR{index}=="0", SYMLINK+="front"

(Save and exit: Ctrl+O, Enter, Ctrl+X)

3. Reload the system and apply:
Bash

sudo udevadm control --reload-rules && sudo udevadm trigger

4. Plug in both cameras and verify:
Bash

ls -l /dev/eye /dev/front

Phase 5: The "Run-Time" SOP

Whenever you sit down to record a new session, this is your exact sequence of operations.

    Plug Everything In: Type-C hub into the left side (Cameras). External SSD into the right side.

    Activate Environment: cd ~/Toyota-Kexxu && source .venv/bin/activate

    Lock the Hardware: Run your exposure locks to ensure 0 frame drops and <10ms skew:
    Bash

    v4l2-ctl -d /dev/eye --set-ctrl=auto_exposure=1 --set-ctrl=exposure_time_absolute=157
    v4l2-ctl -d /dev/front --set-ctrl=auto_exposure=1 --set-ctrl=exposure_time_absolute=166

    Launch the Pipeline: ```bash
    python3 capture_pipeline.py

Visualize the .mkv file with this command
ffplay eye.mkv
